# `/browser-verification` — живая браузерная проверка

Проверяет согласованный сценарий через существующий Chrome MCP:
условия → действия → ожидание → факт → доказательства.

## Использование

```text
/browser-verification [сценарий]
```

Без аргументов используется согласованный в разговоре browser-тест. Если цель
не установлена, команда уточняет её до взаимодействия с браузером.
Результат — отчёт: что прошло, не прошло, заблокировано или не запускалось.
В нём отмечаются версия приложения, связь с исходниками, моки и пробелы покрытия.

Команда не подключает Playwright и не обещает изоляцию браузера. Чужие вкладки
и данные не трогает; опасные внешние действия требуют отдельного согласования.
Сборка, deploy, исправления, файлы отчётов, публикации и коммиты не разрешаются.
Текущие агент и модель сохраняются.

`/delegated-review-chrome` — отдельный аудит записанных результатов, не повторный
тест и не автоматический следующий шаг.

## Подключение

Личная команда для дома и Mac, не часть Common. В `opencode-local/opencode.jsonc`
зарегистрирована через `commands.browser-verification`, `subagent: false` и
`{file:commands/browser-verification.md}`. Текст prompt хранится без YAML frontmatter.
