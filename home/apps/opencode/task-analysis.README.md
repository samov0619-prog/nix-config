# `/task-analysis` — анализ задачи перед реализацией

Разбирает требования и связывает их с минимальными изменениями и конкретными
проверками. Отмечает зависимости, противоречия и блокирующие вопросы;
предлагаемый API отличает от уже развёрнутого.

## Использование

```text
/task-analysis [задача]
```

Без аргументов используется задача из текущего разговора. Если цель неоднозначна,
команда уточняет её. Результат — план в разговоре: требования → изменения →
проверки, с источниками и ограничениями.

Команда только читает и анализирует: не меняет файлы, не запускает тесты, сборки
или браузер, не публикует комментарии и не делает коммиты. Текущие агент и модель
сохраняются.

## Подключение

Личная команда для дома и Mac, не часть Common. В `opencode-local/opencode.jsonc`
зарегистрирована через `commands.task-analysis`, `subagent: false` и
`{file:commands/task-analysis.md}`. Текст prompt хранится без YAML frontmatter.
