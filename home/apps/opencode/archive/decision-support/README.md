# Decision Support — архив

По решению пользователя Decision Support и `decision-check` отключены и перенесены
сюда. Это исторические исходники, не установленная конфигурация. Прежний Nix-модуль
сохранён побайтно как справка: его относительные пути описывают старое расположение,
поэтому импортировать его непосредственно из архива нельзя.

Сохранены прежний модуль, общая инструкция (включая тогдашние todo-правила), skill
с исходной русской цитатой и ручные сценарии. Они не должны попадать в discovery,
`instructions` или активные импорты. Возврат — только отдельным решением пользователя.

Todo не отключён: активный модуль — `../../todo.nix`, переключатель —
`programs.opencode.todo.enable`. Правила заметок теперь находятся в описании
существующего todo-инструмента и доступны только Build/Plan; глобального напоминания
или нового skill нет. Запрос «добавь в todo» остаётся обычным входом без slash-команды,
но запись по-прежнему требует native подтверждения. Автосохранение идей не добавлено.
