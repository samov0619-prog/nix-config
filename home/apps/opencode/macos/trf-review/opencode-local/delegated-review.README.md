# /delegated-review — корпоративный Mac

Актуальные политики: `evidence-v5`, `sources-v1`; fingerprint: `dr-scope-v1`.

- Обычное «поревьюй» остаётся в текущем разговоре, без смены модели/агента,
  fork или ребёнка. Перед анализом читается личный
  `~/.config/opencode-local/review-analysis.md`.
- Явный запрос независимого ревью использует `commands/delegated-review.md`:
  один свежий настроенный `review`, без model override и fallback на `general`.
- Без аргументов сначала выбирается working tree, при его отсутствии — текущая
  ветка от merge-base с локальной базой. Явный scope имеет приоритет; неоднозначный
  target/base требует уточнения, а не произвольного сравнения.
- Командный `AGENTS.md` требует найти применимые внешние требования/ТЗ до анализа
  соответствия задаче и до делегирования. Очевидный источник читается автоматически
  через доступные разрешённые read-only MCP; проверяются связь с задачей и ревизия.
  Неоднозначный/недоступный обязательный источник требует уточнения. Техническое
  ревью без внешнего ТЗ возможно по явному соглашению для этой задачи.
- Родитель передаёт фактический handoff с требованиями, provenance, ограничениями
  и результатами проверок, не development transcript или желаемый вердикт.
- Recovery продолжает только ту же активную задачу с проверенной identity/scope;
  отмена не разрешает автоматическое возобновление. Одна начальная и до шести
  дополнительных попыток имеют общий ledger и ограничения из команды.
- Незавершённое покрытие — `INCOMPLETE`, без итогового вердикта. Ревью не разрешает
  исправления, сборки, установку, коммиты или обход permissions/Plan restrictions.
- Родитель/reviewer не создают временные review scripts/manifests/reports;
  механические вычисления выполняются inline в памяти. Native session/log storage
  разрешён. Файлы и permissions сами по себе не создают security sandbox.

Настройки workflow принадлежат `AGENTS-personal.md`, не командному `AGENTS.md`:
общий файл выбирает только источник требований. Analysis и delegated wrapper
находятся в `opencode-local/review-analysis.md` и `review-system.md` и читаются
напрямую оттуда. В `opencode` остаются только прежние discovery-ссылки команд/роли;
policy-ссылок там больше нет. R3 применяется поверх уже применённого R2.
Это инструкции модели, не программный перехват запросов. Статические проверки
не подтверждают соблюдение моделью или доступ к корпоративным MCP; нужна приёмка
на Mac после установки и `/reload`.
